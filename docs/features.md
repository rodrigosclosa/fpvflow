# FPVFlow features

Everything Gyroflow does works unchanged in FPVFlow. These pages cover what FPVFlow adds on top:

- [Colour grading]({{ '/colour-grading.html' | relative_url }}) - apply a `.cube` LUT and colour adjustments while you stabilize, so the export is already graded.
- [External audio]({{ '/external-audio.html' | relative_url }}) - import a separately recorded track, sync it automatically and embed it in the export.
- [DJI O4 Gyrogate repair]({{ '/gyrogate.html' | relative_url }}) - remove the false rotations that DJI O4 units with the ICM-40609-D gyro record, in the stabilization or as a corrected copy.
